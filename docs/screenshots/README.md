# Template screenshot PERIKSA

Folder ini disiapkan untuk menyimpan screenshot hasil demo. Ganti nama file sesuai daftar di bawah agar dokumentasi mudah dirawat.

| Nama file | Isi screenshot | Ukuran yang disarankan |
|---|---|---|
| `01-login.png` | Halaman login dan akun demo | 1600 × 900 |
| `02-dashboard.png` | Dashboard setelah login | 1600 × 900 |
| `03-kontrak-wizard.png` | Form wizard pembuatan kontrak | 1600 × 900 |
| `04-audit-ai.png` | Hasil audit dan saran AI | 1600 × 900 |
| `05-jejak-audit.png` | Riwayat aktivitas atau perubahan kontrak | 1600 × 900 |
| `06-laporan-warga.png` | Form atau daftar laporan warga | 1600 × 900 |
| `07-kontrak-publik.png` | Halaman kontrak yang diterbitkan | 1600 × 900 |
| `08-health-api.png` | Response `/healthz` atau koleksi Postman | 1200 × 700 |

Contoh pemakaian di Markdown:

```md
![Dashboard PERIKSA](screenshots/02-dashboard.png)
```

Sebelum menyimpan gambar, samarkan token, alamat email pribadi, nomor telepon, NPWP, nomor rekening, dan data lain yang tidak boleh dipublikasikan.
