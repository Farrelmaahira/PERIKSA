# PERIKSA - Frontend Service

Layanan antarmuka web untuk **PERIKSA** (Platform Elektronik Rekam Integritas Kontrak Sistem Akuntabel).

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Library UI:** React 19, Tailwind CSS v4, Lucide Icons
- **Animasi:** GSAP

## 🚀 Memulai Pengembangan
```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

> 📌 **Catatan Pengembang:**  
> Implementasi fitur lengkap dikembangkan di branch `feat/frontend`.
